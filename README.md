# Idle Adventure

A MapleStory-style web idle RPG. Your chibi knight auto-explores a 2D
side-scrolling field, hunts slimes, mushrooms and pigs, and levels up
all on their own.

## Play

Open `index.html` in any browser. No build step, no dependencies.

Or enable GitHub Pages on this repo (Settings, Pages, deploy from `main`)
and play at `https://therladbsgh.github.io/idle-game/`.

## Features

- Fully automatic combat: the hero seeks out monsters, attacks, and
  unleashes Power Strike (costs MP) whenever it is ready
- HP / MP / EXP bars, levels with stat growth and full heal on level-up
- 5 monster types that unlock as you level, with scaled stats
- Gold, kill counter, damage numbers, crits, kill feed
- Zones that change as you level: Slime Meadow, Mushroom Grove,
  Dark Hollow, Ember Fields
- 1x / 2x / 4x speed toggle for the impatient
- Everything drawn procedurally on canvas. Zero assets.
